# **App Name**: UserFlow Admin

## Core Features:

- Add New User: Administrators can add new user accounts by inputting relevant details such as name, email, and initial roles.
- Edit User Profiles: Edit existing user profiles to update personal details, roles, permissions, and other pertinent information.
- Search & Filter Users: Efficiently search for users by various criteria (e.g., name, email, role) and apply filters for refined results.
- Smart Role Assignment Tool: An AI tool that suggests appropriate user roles and permissions based on the user's provided job title or department description, leveraging best practices for security and access control.

## Style Guidelines:

- Primary color: Bright Yellow (#FFE600). This vibrant hue will be used for key interactive elements, highlights, and active states to command attention against the dark background.
- Background color: Deep Graphite (#1E1D15). A dark, almost black, background providing a modern and sophisticated foundation that ensures legibility and focus on content.
- Accent color: Fresh Lime Green (#A4FF80)). This muted lime green, analogous to the primary yellow, offers a contrasting yet harmonious option for secondary actions, borders, and subtle distinctions within the UI.
- Headline and body font: 'Inter', a grotesque-style sans-serif font known for its clarity and neutrality, ensuring high readability for data and administrative tasks.
- Use a set of clean, minimalist line icons for actions like 'add', 'edit', 'search', and user profile indicators to maintain a professional and unobtrusive aesthetic.
- Adopt a structured, grid-based layout for consistent placement of elements. Emphasize data tables with clear row/column distinctions and ample whitespace for readability.
- Incorporate subtle, quick animations for form submissions, user feedback (e.g., success messages), and tab transitions to enhance user interaction without distraction.
